# 平坦地圖橋面突起修正（2026-09-12）

使用者回報 v0912n、167 次、22:12、知本—太麻里附近橋面突然拱起。實際重播可重現：平坦地圖的軌面短距離升降約 6.8m，局部坡度接近 8%，每節車也跟著上下折。

## 原因與修正

`terrainValues` 已有地形模式的縱坡處理，但預設平坦地圖仍讀舊 `offsets`。原始橋梁 +8m 層位在短橋兩端按 8% 過渡，每個短片段都可能造成突起。先前只驗地形模式的坡度，沒有擋下這種畫面。

新增 `flatOffsets`，在全網共用來源節點上，以里程加權的 200m 平滑尺度柔化短橋與引道，之後同時限制露天坡度及相交淨距。長高架中段保留原本高度。露天取樣原本不低於地面時，以 0m 為下限；原有地下引道可保留負值，但不低於舊剖面，避免柔化時把洞口旁的橋面拉進地下。露天顯示坡度上限為臺鐵／高鐵 2.5%、林鐵 6%、捷運／輕軌 4%；339 處不同層交叉維持至少 7m 淨距。地下疊層保留原 8% 約束，因部分來源接頭在短距離內換層，硬套露天上限會與淨距互相矛盾。這些都是顯示估計，並非實測或工程標高。

算繪端的軌道、橋面、車廂及跟車鏡頭共用 `railHeight()`，平坦模式改取 `flatOffsetM`。原 `offsetM` 保留給結構／地下分類，原 `values`、`offsets`、`terrainValues` 保留給地形與覆土計算。全量重建後逐筆比對 5,010 份原始剖面，除新增欄位外完全一致；未改平面幾何、班表、派軌或列車位置。
