# 林鐵・森之折返：一車一景樣板 02

2026-09-10，基於藍皮樣板 `a3f9d4b6`，獨立分支 `codex/garage-alishan-0910`。

## 預覽

```sh
# /private/tmp/railisland-alishan-0910
python3 -m http.server 5252 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:5252/prototypes/garage-alishan/`。右上可返回同一工作樹的藍皮海岸。

桌面預設山林全景，手機預設跟車。可切山中晴日／午後斜光／林間夜色、暫停、旋轉與縮放。「看折返」跳至第一個折返前兩秒，隨後實際停車三秒並換線倒推；減少動態偏好下保持暫停。完整往返約 132 秒，循環回到起點時不重設列車位置。

## 場景與路網

- 沿用 DL38 與兩節 `alicoach` 的既有三節示意編組。沒有新增或改寫模型資產，不碰護照／收藏條件。
- 三層山坡路基、兩個折返留置端、山腳與山上小站、針葉林、岩塊、木質底座與夜間站燈。這是阿里山林鐵的微縮意象，不宣稱復原特定分道站或真實坡度、里程、樹種。
- `alishan-route.js` 的三條支路各有自己的 3D 弧長，兩端留置線共享位置；沒有把分岔壓成一條幾何線。
- 六個行駛階段：下層前進 → 中層倒推 → 上層前進 → 上層倒退 → 中層前進 → 下層倒退。每個端點先減速至零、停三秒，再接下一段。
- 完整編組加餘裕必須容納於留置線，否則建立旅程時拒絕。換線時全車已離開道岔，車廂位置、朝向與俯仰皆連續，不瞬間翻頭。
- `consist-3d.js` 以各車前後轉向架的 3D 取樣建立車身座標基底；車廂與車鉤一起俯仰。舊 `garage-model.js` 的平面 follow 未改動，因此藍皮樣板不受影響。
- 地表由同一組軌道高程刻出路基，站房周圍另有平整站坪；驗證用射線打到實際三角網格，並非只比較高度函式自身。
- 林木、枕木、站體細節用 InstancedMesh 合批。直接繪製到獨立 WebGL canvas，不載背景地圖；暫停／背景分頁停止動畫，離頁釋放資源。

## 驗證

`node scripts/verify_garage_alishan.mjs`，結果與截圖在 `output/alishan/`，不進版控。

- 純路網測試：六個階段接點含車尾／車頭端點，位置連續；路線具有高差與坡度。
- Chromium／WebKit：實際 DL38 與兩節林鐵客車像素 A/B；全景與跟車構圖；三時段截圖。
- 六階段各三個取樣時刻，前後轉向架位置對實際地表三角網格的道床淨空，並驗俯仰不為零。
- 六個端點皆停車三秒；相鄰階段不跳位／不翻頭。另實際播放第一折返動畫，確認停車後進入第二條支路倒推。
- 360／375／390／414／520／768／1280 px 真觸控，全按鈕及返回連結的命中、尺寸、兩兩相交和水平溢出。
- 視角與時段多次切換不增加幾何／貼圖，暫停不重繪，手機及減少動態偏好。

尚未整合正式車庫或部署。A54／iPhone 真機長時間效能與耗電仍待實機驗收；桌面手機模擬不代替真機。
