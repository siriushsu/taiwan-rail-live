# 林鐵微縮道岔修訂

本機修訂，尚未發布。此場景為之字形折返的微縮示意，不宣稱重建特定車站的道岔型號或工程尺寸。

## 問題與修改

原先兩條完整軌道直接重疊，分岔附近的枕木互相穿插，坡度讓轍叉處鋼軌高度不一致；轉轍牌是固定裝飾。這次改成共用水平岔床與加長岔枕，分開基本軌、尖軌、轍叉輪緣槽及護軌，增加可動連桿、扳柄及雙面指示牌。保留原有六段旅程與留置線長度。

四次分道折返都在完整編組通過道岔後停止。停車 0.6 秒開始轉轍，1.8 秒完成，原有 3 秒停留結束後反向開出；車頭不在原地旋轉。尖軌、連桿、指示牌以同一進度驅動；暫停、跳轉預覽時間及循環播放皆可重建正確狀態。山頂與山腳普通折返不切換分道。

林業保育署的[林業軌道介紹](https://recreation.forest.gov.tw/Railway/Introduce)說明之字形登山及「分道」的轉轍器控制路線切換；本次動作時間與道岔尺寸為微縮展示設定，不當成實際營運規章。

## 驗證

- `scripts/verify_alishan_turnouts.mjs`：Chromium、WebKit 檢查六階段進路、全列淨空、停車切換、道岔水平高度、四次轉向的尖軌／標誌狀態與畫面實際像素差。
- `scripts/verify_garage_alishan.mjs`：既有折返不瞬移、地形貼合、日夜、平移、360／375／414／768 手機觸控等回歸。
- 實際執行結果與截圖留於 `output/alishan-turnouts/`、`output/alishan/`。真機效能仍待驗；客車外觀考據是另外一項待辦，本次沒有改客車模型。

本輪結果：道岔專項 12/12、既有林鐵回歸 66/66 通過；已檢視全景截圖與使用者本機分頁的跟車近景。
