# 車庫介紹的出處

大多數只有中文維基一個來源，部分有新聞或官方頁佐證。出處互相矛盾、或只有單一來源又不重要的說法就不寫進介紹（例如福森號的啟用日只寫「2024 年夏天」）。
重大事故不寫進介紹。

以後改介紹：新的年份或數字先找到出處，加進這份清單再改 `train-garage-intros.js`；App 用 native 的 `tools/gen_garage_intros.mjs` 從網頁釘版重產。
