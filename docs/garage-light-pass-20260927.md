## 02 阿里山（`5070aa88`）

- **驗證**（主對話在最終檢查點重跑）：`verify_garage_alishan_fx` 11/11、`verify_garage_alishan` 66/66、`verify_alishan_sign_motion` 2/2、`verify_alishan_turnouts` 12/12。
- **退件兩次**：
  - 第一版雲只在板子一角一團，螢火蟲夜裡看不到。
  - 第二版螢火蟲是直徑 17～24 px 的白色硬邊八角圓盤，像氣球。原因是我開的判準只有下限（≥4 px），這次補上上限、核心大小、柔邊度、顏色。

## 教訓

1. **agent 看不到自己的 token 用量，給它上限它守不住**：十分最後一輪給 25 萬，實際用了 86 萬。agent 在跑時要由主對話定時量用量，到上限就叫它收尾。
2. **判準兩邊都量**：螢火蟲只設下限，結果做成氣球。
3. **形狀寫成量得到的幾何，不寫形容詞**：寫「頂部微鼓」得到蛋形。
4. **視覺驗收一定看側面低角度並放大裁切**：程式拼的樹、太小的天燈、氣球般的螢火蟲，都是這一步抓到的。
5. **agent 回報的 N/M 要自己重跑核對**：南迴曾把 66 報成 60。
