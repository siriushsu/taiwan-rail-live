# 車庫主題系列發佈計畫

日期：2026-09-12
狀態：依使用者確認的「四款首發、每週不同主題」方向安排；以下是內部製作順序，尚未公布日期或部署。

## 發佈原則

- 首發一次推出目前四個場景：藍皮南迴、阿里山林鐵、新自強高架、DR1000 十分。四景目前是可操作原型，仍需接入真正的車庫。
- 首發後，以每週一個主題、通常 2～3 款主角車為目標。每波最多新做一座主要場景，其餘使用同主題下的共用景或小幅變體。
- 「主角車／體驗」與目錄項目分開計數。機車與其客車合為一套體驗，不把每節客車當成另一款新作宣傳。62 個目錄項目是長期素材池，不是 62 次發佈承諾。
- 同一波完成一個小系列；下一波切換另一種鐵道風景。經典車、都市捷運、通勤、海岸、森林與蒸汽交錯，保留後續亮點。
- 首發日確定後才填日曆日期。下表 W1 表示首發後第一個發佈週，不是現在立刻開始倒數。
- 未完成專屬場景的其他車款保留既有車庫功能；新增場景依已完成清單開放，不顯示尚未實作的景色名稱。

首發完成條件：

1. 四景接入車庫，選車、進入、退出、切換車款、資源釋放均可正常操作。
2. 共用日出／白天／黃昏／夜晚與依開啟時間設定的控制；放大能接到跟車。
3. 跟車隨朝向轉動，逐景處理遮車。藍皮已做，不能推論另外三景已完成；阿里山折返時避免突然旋轉 180 度。
4. 環形場景不加倒退；阿里山保留必要折返與多段旅程。
5. 驗兩種瀏覽器、手機操作與完整列車可見度，並安排實機效能檢查。原型驗證不等於整合後驗證。
6. 依專案流程更新版本及公開更新紀錄、驗證預覽後再安排正式部署。本計畫本身不執行部署。

## 後續保留的主題庫

不提前綁死週次，也不一次把特色場景用完：

- 蒸汽支線／花東蒸汽：CK124、CT273，各自保留不同景色。
- 山嵐與海風：觀光列車系列，可分山線、海線兩波。
- 鳴日與旅行：鳴日編組及旅程場景。
- 高鐵速度感：700T 與特色高鐵站。
- 機場線：普通車、直達車，共用一座機場線場景。
- 北捷地下站：C321、C341，讓都市系列換一種空間。
- 淡海／安坑輕軌、環狀線／其他城市捷運：按城市拆小系列。
- 柴油機車與調車場、電力機車與幹線、其他通勤車：共用景較多，可作較輕量的製作波次。
- 特色車站回訪：冬山、新竹、臺南等，未來也可以替已推出車款增加新景，不必每波都依賴新車款。

以上是候選主題，不是完成品清單；尚未逐款分派的目錄項目仍保留在素材池。

## 每週製作節奏與 token 控制

1. 週初鎖定本波：只確認主題、2～3 款主角、最多一座新景及驗收條件。只讀與該波相關的程式與素材。
2. 製作分開交付：先場景與編組，再跟車／日夜，再必要驗證。每段留下 commit、簡短結果與下一步。
3. 週中預覽：先確認構圖與列車辨識度，再補必要細節；避免完成後整座推翻。
4. 發佈前停止加新內容：修掉破面、閃動、穿地、遮車與操作問題。測試依改動影響選擇；共用控制器改動才擴及所有已發佈景。
5. 維持一波備稿：首發穩定後，盡量讓下一波已可預覽，再對外承諾週更。高工作量特別篇提前製作。
6. 同時只開工一波，下一波只做必要參考整理。每次 token 不足時停在可續接的提交點，不以刪減必要驗證換取上線。
7. 高工作量波次若超出可用時間，可順延或在當週推出既有景改善；不把未完成場景硬上線。週更是目標，確切日期只公布已接近完成的內容。

## 對外呈現

- 發佈格式：「車庫新風景｜本週主題」，附本波車款、代表畫面與可體驗內容。
- 只預告下一個主題；更遠的排程保持內部可調整。
- 首發說明四款已可體驗，後續按主題追加；不宣稱 62 款場景已完成。
- 以上是文案安排，未代發任何公開訊息。
