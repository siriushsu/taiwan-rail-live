# 藍皮・山海之間：一車一景樣板 01

2026-09-10，基於 `5d946290`。本機試作；未串接正式車庫選單、未部署。

## 預覽

工作樹：`/private/tmp/railisland-south-coast-0910`。

```sh
python3 -m http.server 5251 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:5251/prototypes/garage-south-coast/`。

桌面預設山海全景；手機首次開啟預設跟車，避免列車縮成無法辨識的小點。可切換晴日／夕照／入夜、暫停、反向、縮放，支援拖曳旋轉、雙指縮放與鍵盤。減少動態偏好預設暫停。

## 視覺與實作

- 參考 Whistlevale 的有界微縮世界、分層構圖、接地陰影與夜間暖窗光；未複製網站程式、美術資產或引擎。
- 南迴沿線的靠山面海意象，使用木質底座、海灘／礫石／岩岸、山丘闊葉樹叢、小站與海側低欄杆構成場景。不是多良或其他實際車站的復原，也不是實際路線。
- 藍皮沿用既有車庫 R135 模型與兩節 `bluecoach`，不新增模型或貼圖檔，不更改原始模型及收藏紀錄。
- `rail-3d/garage-scenes/south-coast.js` 提供 group、path、update、themes、camera、label、dispose。場景固定 seed 生成；海浪以材質 shader 繪製，地物合批繪製。
- 車輪高度沿用車庫既有 `.18`，軌道與列車使用同一弧長取樣。這個場景軌道平坦；山丘位於路線中間，背側回程會被山丘遮住。沒有宣稱已支援爬坡或之字形折返。
- 反向只改弧長速度，車頭朝向與編組位置維持連續；這是小模型倒車，不是調頭或機車換端。
- 直接使用獨立 WebGL canvas，沒有每幀拷貝到 2D canvas，也不載入背景地圖。最多約 30 fps，背景分頁／暫停停止動畫，離頁釋放資源；WebGL 中斷提供重新開啟。
- 目前是獨立的展示頁；`prototypes/` 受既有部署排除規則保護。正式車庫、其 catalog 及 index.html 未修改，因此未增加正式站更新紀錄。

## 驗證

執行 `node scripts/verify_garage_south_coast.mjs`，結果與截圖位於本機 `output/south-coast/`（不加入版控）。

- Chromium／WebKit：藍皮與兩節客車真實像素 A/B，每節都有可見差異；海面投影像素為藍綠色。
- 晴日／夕照／入夜、跟車完整構圖、正反向前進、停車換向無座標及朝向瞬移、彎道三節編組。
- 360／375／390／414／520／768／1280 px 真觸控、全按鈕命中、觸控尺寸、兩兩相交及水平溢出檢查。
- 多次視角／時段切換，幾何及貼圖數不累積；暫停不持續繪製；減少動態偏好與手機初始構圖。

手機模擬不等於 A54／iPhone 真機效能驗收，尚未量測長時間耗電。這次先驗收美術方向；場景註冊表、完整車款對應、故事資料與正式車庫整合留待樣板確認後實作。
