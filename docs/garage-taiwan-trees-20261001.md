# 車庫場景・台灣常見樹種（設計 spec，2026-10-01）

## 1. 目標

車庫各場景的闊葉樹，換成依地點挑選的台灣常見樹種低多邊形模型。風格維持微縮模型：平面著色的低多邊形，不用透明貼圖，也不做寫實葉片。每個樹種要一眼認得出來，例如小葉欖仁的層狀枝、筆筒樹的放射羽葉、林投的劍葉叢。

成功的判準：
- 一般訪客看全景，能感覺到「這是台灣的街道」「這是台灣的山／海邊」。
- 場景其他東西不因換樹而移動或變色。
- 效能不明顯變差。

不做：
- 阿里山（已是針葉林）。
- 椰子、檳榔、竹子（已有專屬零件）。
- 植物學上的精確度（只求認得出樹種）。
- 季節變化。

## 4. 各樹種的造型規則（低多邊形）

| 樹種 | 識別特徵 | 幾何做法 | 顏色 |
|---|---|---|---|
| 小葉欖仁 | 主幹挺直，側枝輪生水平展開，一層層像疊起來的傘 | 直幹＋3～5 層扁平圓盤葉層，由下往上逐層縮小，每層之間留空隙 | 亮黃綠 |
| 鳳凰木 | 寬而扁的傘冠，比樹高還寬；初夏開紅花 | 短幹分 3～4 根斜枝，上面是一片寬扁傘冠（由多團扁葉簇組成） | 細葉綠；約三成葉簇改成朱紅（固定做成開花期） |
| 台灣欒樹 | 圓到蛋形的樹冠；秋天頂部黃花、粉褐果 | 直幹＋圓冠（5～6 團葉簇） | 中綠；頂部 1～2 團黃色或粉褐 |
| 榕樹 | 寬而厚重的圓冠，垂掛氣生根 | 粗短幹分枝，寬厚圓冠（6～8 團）；冠下垂 4～8 條細柱當氣生根 | 深綠 |
| 相思樹 | 淡灰綠的傘形；樹幹常歪 | 傾斜主幹（5～15°）；葉簇小而多，邊緣較碎 | 灰綠 |
| 山黃麻 | 傘形，中等高度 | 直幹分叉，傘形冠（4～5 團），偏扁 | 中綠、略黃 |
| 筆筒樹 | 直柱莖，頂端一圈放射狀大羽葉 | 細長柱幹（可略彎）＋頂端 8～12 片下垂的長菱形葉片（雙面，不透明） | 莖深褐；葉亮綠 |
| 血桐 | 矮胖濃密的傘形；大圓葉 | 短幹，低而寬的圓頂冠；葉簇面數低、塊面大 | 深綠帶點藍 |
| 林投 | 叢生，螺旋排列的劍形葉；底部有支持根 | 2～4 支斜幹，每支頂端一叢放射狀細長三角葉；基部 3～5 條斜插的支持根 | 黃綠；幹灰褐 |
| 黃槿 | 矮闊的圓冠；黃花 | 短幹，扁圓冠；冠面點綴少量黃色小塊 | 中綠＋黃點 |

建模前，每一種都要對照林務局原生樹木平台（https://nativetree.forest.gov.tw/Tree）的照片確認輪廓。照片只看，不存檔，也不進 repo。

## 5. 架構

**模組**：新增 `rail-3d/garage-scenes/taiwan-trees.js`，取代 `broadleaf-v2.js`。broadleaf-v2 的葉簇做法併進來，作為「圓冠類」的共用部件。第 2 階段完成時刪除 `broadleaf-v2.js`。

```js
const trees = createTaiwanTrees({geo, material});      // 由場景 kit 提供 geo／material，負責 dispose
trees.plant('terminalia', x, y, z, h, {seed});         // seed 省略時用座標雜湊；不吃場景共用亂數
trees.plantMix(MIX.city, x, y, z, h, {seed});          // 依比例抽樹種（抽法用座標雜湊，決定性）
trees.plant(..., {maxReach, maxPatch});                // 逐棵限制（可省略）：樹冠水平半徑上限，超過時 plant 只降高（最多到 75%），plantMix 先改試組合裡其他樹種、都放不下才取最窄的再降高；樹下貼片半徑上限，超過就不鋪貼片（位置不動）
const houses = trackHouses(props);                     // 登記 props 蓋的房子外框；houses.clearance(x,y)＝到最近房子的距離（maxReach 取它減餘裕），houses.outside(x,y,gap)＝樹心落在房子裡時外推
trees.build(parent);                                   // 種完一次合併
trees.dispose();
export const SPECIES = [...], MIX = {city, northForest, eastCoast};
export function treeShape(species, seed, h);           // 純函數，給驗收工具重算幾何
```

**繪製方式**：樹不會動，所以 `build()` 把整批樹烘成**一個合併的 BufferGeometry**，用一個材質。整批樹 1 個 draw call，比現在的 2～4 個還少。合併沿用 guanghua 已有的 `mergeParts` 做法。開花色、氣生根都是頂點色，不另外加材質。入夜、夕照照舊只靠場景光變暗。

**著色**（2026-10-01 三方案對照後定案，預設 `shading:'volume'`）：
- 冠的頂點色做假 AO：冠底與冠內側暗，冠頂與冠外緣亮。每棵再加少量色偏，用座標雜湊，保持決定性。
- 冠的法線改成從所屬冠團中心往外的體積法線，冠的光影成一團量體，刻面雜訊消失，輪廓仍是低多邊形。
- 樹幹與枝維持平面著色：非索引幾何，寫入每個面的法線。
- 樹幹基部略外擴，樹下鋪一圈暗地面貼片。坡地上的樹要傳 `ground:false`，否則貼片會一半埋進土裡、一半懸空。
- 扁冠與層狀冠要分成多個冠團；若一株只算一團，背光側會整片變暗。新增或修改樹種時要留意。
- `'gradient'`、`'flat'` 兩種模式只留作對照。對照圖在 `~/Desktop/車庫B-檢查點/闊葉樹/著色對照/`。

**三角形預算**：
- 市區樹種每棵 ≤ 400 tri。山林、海岸樹種每棵 ≤ 220 tri，因為這兩類棵數多。
- 每景樹的總三角形 ≤ 6 萬，場景總三角形增幅 ≤ 15%。
- 超過預算就減葉簇數，不做執行期的 LOD。樹的位置固定，YAGNI。

**共用亂數**：每個呼叫點照舊補吃原本那套做法消耗的共用亂數次數（props.broadleaf 是 9 次；south-coast、shifen 依各自程式），確保樹以外的東西逐像素不變。

**快取**：每個階段改到的模組，import 的 revision 字串都要升版，避免審看的人看到瀏覽器快取的舊版。

## 7. 驗收（每個階段）

1. **樹以外不變**：每個改到的場景，HEAD 與工作樹各算繪一次，兩邊都把樹藏掉後逐像素比對，差異必須為 0（白天、入夜）。要附正向對照：不藏樹時必須抓得到差異。guanghua 另跑 photo_check 66/66。
2. **不穿插**：樹的樹幹底部、樹冠，與房子、軌道、路堤、道路、底座邊緣的相交檢查為 0。允許的例外要列出來，並和舊樹比較深度。
3. **效能**：每景 draw call、三角形前後並列，符合第 5 節的預算。
4. **決定性**：同一頁載入兩次，樹的幾何逐值相同。
5. **執行期錯誤**：場景頁、原型頁，白天與入夜，pageerror 與 console error 都是 0。
6. **手機**：360、414 寬截圖，看樹不糊成一團。
7. **既有 harness**：各景既有的驗收工具重跑全綠，例如 guanghua 的 V2、V5、V6，場景分頁驗收工具 previews。預覽圖重產。
8. **公開衛生**：新增的註解只寫做法與理由。

樣張的「像不像」照評分 rubric（識別特徵是否清楚、與場景風格是否一致）評，造型確認後才往下一階段。

## 8. 風險

- **樹種外型細節多為轉述**：高度、花期等多半來自轉述，建模前要對圖鑑（第 4 節）。
- **筆筒樹、林投的平面葉片**：雙面的薄片在陰影 pass 可能出現瑕疵，第 1 階段的樣張就要檢查陰影。
- **duoliang 的隧道山脊樹**：由 `scene-detail-kit.js` 種植，這是共用 kit。改呼叫點時，不得影響其他用到這個 kit 的場景。
- **south-coast、shifen 的樹與 Blender 零件包在一起**：棕櫚與竹子也在同一包。換樹時不動那個資產檔，只是不再引用其中的闊葉零件。

## 9. 第 1 階段結果與留給後續階段的事（2026-10-01）

`taiwan-trees.js` 的 10 個樹種、預設 `shading:'volume'`，已通過兩輪獨立評審與複驗：
- 識別特徵與瑕疵兩項，沒有任何樹種拿到 1 分。
- 浮件與縫隙 0。純黑面 0。冠底近黑 ≤0.21%。
- 預算內，決定性 0 差。樣張頁 error 0，整批 1 個 Mesh、1 次 draw call。
- 評審報告與截圖在 `~/Desktop/車庫B-檢查點/闊葉樹/評審/`（含 `複驗/`、`複驗2/`）。

第 2～4 階段換進場景時要處理的事：
- **地色**：`ground` 沒傳就不鋪樹下貼片，每個場景都要傳自己的地色。坡地上的樹傳 `ground:false`。林投一律不鋪。
- **薄葉的 shadow acne**：血桐、筆筒樹這類 0.005H 的薄葉，葉面會出現細條紋，原因是陰影圖的深度精度不夠。試過有效的對策：替樹的 mesh 掛 `customDepthMaterial`，寫進陰影圖的深度加 `min(2·fwidth(z), cap)`。cap 取 0.001～0.002，不加上限的話榕樹的地面陰影會破洞。cap 是正規化深度，要依各場景陰影相機的 near/far 實測調整。polygonOffset 在 three r170 無效。
- **血桐的樹基外擴**：有傳地色時，約 70% 的樹保留外擴，其餘被葉柄用掉預算。
- **建構時間**：200 棵北部山林混種約 90 ms（冷啟動），比修瑕疵前慢 1.6～2.4 倍，原因是零件接觸判定。
- **暫緩的造型意見**，等種進真實場景後再決定：
  - 筆筒樹第一眼像椰子，內段羽片在側視圍成漏斗。
  - 山黃麻的圓頂不夠傘形。
  - 鳳凰木的冠塊像板材。
  - 台灣欒樹頂部的花色塊像帽子。
