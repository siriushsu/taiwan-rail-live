# 下一波：多良與經典平交道

2026-09-13 本機原型。使用者要求先製作下一波兩景，注意遊客、道路車輛與燈光，並於製作中指定「不用環形、單向穿越出畫面」。未推送、未部署，尚未接入正式車庫／App。

## 可用內容

- `prototypes/garage-duoliang/`：多良紅欄杆、高架觀景月台、封閉側面的擋土壁、岩岸、海面波紋、兩端拱形隧道與內襯、站名板、木椅、階梯、月台燈。17 位遊客含拍照、戴帽、兒童及兩位散步者，位於欄杆後方。
- `prototypes/garage-crossing/`：台灣街角意象，兩側街屋、機車騎士／安全帽、四輛汽車、兩輛機車、候行路人、田畦、圍籬、排水溝與盆栽。道口含雙面交替紅燈、黃黑遮斷桿、警示十字與緊急按鈕箱。行車朝向、停止線與入口遮斷桿對應。
- 三款可換車：藍皮 R135、DR1000、新自強 EMU3000，皆為既有三節示意編組，不宣稱 62 款都已驗。換車保留場景、時段、播放／暫停與觀賞模式，依新編組長度重算鏡頭及遮斷時序。電聯車展示時顯示示意電車線；自由換車不代表實際年代、班次或現況配對。
- 四時段：依臺灣時間初始化日出／白天／黃昏／夜晚，可手動切換。列車沿用既有頭燈光束、窗光與尾燈；場景路燈有實際照地光，店窗與汽車燈具發光，汽車頭燈有道路光束，警示紅燈有微弱環境紅光。
- 單向進場、通過、離場。可見鐵道 x=-35～35，整列在場外 x=±90 緩衝區才重設進場位置；不反向、不畫回程軌道。跟車到出口時鏡頭停留，列車離開景框後再等下一次進場。車身、車鉤、頭燈光暈與光束處理場景邊界。
- 暫停同時凍結車流、遊客步行、水波及警示燈展示時間；減少動態設定預設暫停，背景分頁停止動畫。

## 平交道展示邏輯

以編組頭尾與道路範圍計算接近與清空。車頭抵達前先警示、再落桿；全列離開後稍候升桿，完全升起再放行汽機車。換較長編組不會提早升桿。動作時間是微縮展示設定，不當作實站控制規章。未加入來源不明的實錄警鈴。

## 考據與簡化界線

- [交通部觀光署：多良車站](https://www.tad.gov.tw/m1.aspx?id=A12-00377&sNo=0001016)：山坡、高架月台、欄杆、海景與兩端隧道的地域基礎。頁面描述含歷史資訊，不當作最新工程測繪。
- [許傑原始攝影：多良車站](https://journey.tw/duoliang-station/)：2018 年發表、2021 年更新，含 2011 舊照；本次實際檢視紅欄杆、月台與夜間列車通過的原照。照片僅供外觀研究，沒有下載、重製貼圖或隨場景發布。
- [台鐵平交道宣導](https://www.railway.gov.tw/tra-tip-web/adr/customized_info?I=BOdk82vOPKw4nr9W8kfiZqgN%2Bif9LX%2B2JNc1p3BG4HGpGf0rzDC8bMRG3GqlEN4q5Sm8csVG1EI%3D&selectIndex=0&site_preference=normal)：遮斷桿完全升起才通行、緊急按鈕等辨識元素。街角原型非特定道口重建。

多良以紅欄杆經典印象組合微縮景物，未固定成某年完整實站模型；本站塗裝、自由選車、觀光動線及電車線為展示設計。不可宣傳為現在多良的精確復原。三款列車未在本輪重做外觀考據；既有模型未完成的精修項目仍保留。
