# 地景與歷史建物 v0909b

地圖新增獨立「地景」風格，整合先前地景底圖、ESA WorldCover、樹群與本輪 25 組歷史建物。保留原有 22 款地標及最新車庫、捷運車次、收集章功能。

## 校正與範圍

25 組分為 47 個定位部件，近／遠景二進位合計約 19.4 MB；只載入視野附近所需 LOD，沿用既有裁切與快取上限。園區每棟依自己的座標查詢地形，未知地形時先不顯示，沒有拿鐵路高程填補建築海拔。

- 多數主體用 OSM 建物輪廓的方向及包圍框校正。這不是逐邊測繪復原。
- 勝興、車埕、橋頭以官方場域資料配合網站衛星底圖交叉比對主屋頂，尺寸與屋頂外框保留為目視估計。
- 斗南改為沿鐵道連續六棟；官方面積比例用於分段尺度，分界及序號不是已核實的室號。
- 嘉義補上官方園區圖北端的第二代製材工場，與南側動力室各自定位。
- 花蓮主廳舍修正為 L 形雙翼並補轉角塔樓，避免將個別室內房間輪廓當成整翼外框。
- 北門驛採官方舊站位置與面積；沒有誤用北側新站輪廓。
- 高度、部分立面與附屬構件仍是風格化估計；未定位的附屬構件不入圖。每組的 `omittedUnlocatedComponents` 與來源資料保留完整。

定位資料在 `rail-3d/assets/historic-buildings-v2/placement.json`，逐組說明在各 `model.json`。可重建的 Blender 程式及來源在 `prototypes/tiny-trains/blender/historic-v2`；該資料夾不部署至網站。原生工作檔另留在本機工坊。

## 檢查

`verify_historic_assets.mjs` 已掛入正式出貨流程，檢查 25 組清單、定位契約、元件完整、雙 LOD 雜湊、頂點與法線。格式驗證不代表現實精度認證。

地圖驗證使用 Chromium 與 WebKit，涵蓋各組近／遠景、底圖切換，以及 360、375、414、768 的真觸控。地景另檢查中間寬度、一般與全螢幕下的控件命中／相交、跟車位置不變與樹群更新時機。

本輪亦修正拖曳開始後舊樹群工作仍可能提交的時機：相機拖曳期間取消重建，結束後再排程。
