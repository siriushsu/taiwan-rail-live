# 多語化 MVP 覆蓋範圍

更新日期：2026-08-28

## 已納入 zh-TW／en／ja

- 首屏、系統分頁、主要導覽、工具列、設定與語言切換。
- 車站與路線名稱、列車種類、方向與終點；外語站名缺漏時退回繁中。
- 車站搜尋、來車看板、列車跟隨卡、定位／落釘、載入與網路降級提示。
- 營運異常、即時資料中斷與班表備援提示。
- 軌島通行證入口、方案／恢復購買狀態、續訂與免費層重要說明。
- 隱私權政策與服務條款全文。

## 本階段刻意保留繁中的內容

- 公開更新紀錄與完整開發歷史。
- 長篇品牌介紹、部分使用說明的延伸故事與特殊車站／特色列車介紹。
- 護照內的圖鑑故事、成就名稱與少數非核心收集文案。
- 實驗中或預設關閉的校正貢獻、診斷與開發者專用畫面之長篇說明。
- TDX／營運機構臨時公告、活動或合作內容若來源只有中文且字典沒有對應，會安全保留來源原文。
- 使用者自行輸入的地點名稱與匯入清單名稱不翻譯。

上述內容不會顯示 `undefined` 或翻譯 key；缺少外語時一律安全退回繁中。

## 稽核與驗證

- `node scripts/check_i18n.mjs`：檢查 en／ja key 對齊、runtime literal key、核心 renderer 硬編碼，以及法務頁文字覆蓋。
- `node scripts/build_i18n_station_names.mjs`：由現有資料與 `docs/i18n` 補充表重建站名索引。
- `node scripts/verify_i18n.mjs`：以 Chromium／WebKit 驗證即時切換、保存、動態面板、法務頁及手機觸控與版面。
