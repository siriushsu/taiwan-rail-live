# 高雄輕軌來車看板方向修正

## 問題與範圍

兩向的末站同為籬仔內，舊版以終點名分組後只取前兩班，既讓方向文案相同，也會擠掉另一向的班次。
官方方向依據：[高捷經貿園區站頁](https://www.krtc.com.tw/KLRT/station_info?n=C6)營運說明第 6、7 點。

本次僅修改公開前端的看板分組與方向文案；不改班表、官方倒數、GPS 配對、列車位置、身分或 Core 開關。
高雄 C 線改依本站到下一站的環線方向＋真正終點分組，每向各取最近兩班；查詢摘要每向取一班。
0→37／37→0 的環線接縫也計入，不能用索引大小猜方向。
方向提示包含下一站與本趟前方的辨識站，選站只到此趟終點，不能指向下趟或已經走過的站。
真正終點仍保存在跟隨提示，未把駁二等途經站冒稱為終點。

## 可重現例子

平日班表、經貿園區 08:57：原版只列逆行 09:00／09:08，漏掉順行 09:11／09:26；新版四班皆保留。
這是固定班表的測試情境，不是當日即時預報。
顯示順行「經軟體園區 · 駁二大義」、逆行「經夢時代 · 籬仔內」，不再全部寫往籬仔內。

## 驗證

- `node scripts/verify_klrt_board_directions.mjs`：456 組，平日／假日、38 站、08:57／18:00／21:30、一般／全台同框。修前失敗、修後通過。
- 非輕軌對照：高捷紅橘線各套班表、全站，分組結果逐班與 d09307a8 相同。
- `KLRT_BOARD_MUTATION=merge`：退回只按終點分組，測試失敗。
- `KLRT_BOARD_MUTATION=seam`：改以索引大小判環線方向，測試失敗。
- `node scripts/verify_klrt_board_browser.mjs`：headless Chrome／WebKit × 360／375／390／414／768，共 100 組版面狀態；涵蓋明暗、全畫面、摘要、英日文、特大字、公告及更多抽屜。真觸控每向班次，核對同一 trip 的跟隨；方向與途經文字不截斷、無水平溢出、無頁面例外。
- `node scripts/check_i18n.mjs`、`node scripts/verify_changelog_copy.mjs`、`git diff --check` 通過。

瀏覽器依賴可用 `KLRT_TEST_PLAYWRIGHT=/絕對路徑/playwright/index.mjs` 指向既有安裝；不需在主工作樹安裝或寫入任何檔案。
看板改善不構成定位精度改善的證據，也不代表私有高雄輕軌 Core 已完成驗收。
