# 地景顯示修正與夜間頭燈 v0912k

## 範圍與修正

- 台北地下段與高鐵林口隧道：橋墩的高度備援判斷漏掉地下排除，正 offset 的隧道會只生成柱子、沒有橋面。現在先以同一個地下判定排除，再判斷高架與高填方。沒有更改股道座標或高程。
- 真正橋梁保留連續箱梁、鋼軌與枕木；墩身改為較細的示意比例，側面顏色降低對比。
- 明亮外觀預設關閉日夜光影，暗色預設開啟。兩種外觀分別保存手動選擇；`sun=on/off` 仍可覆寫測試初值，手動操作後以使用者選擇為準。新設定使用 `trainmap-sunlight-v2-light/dark`，不繼承舊版跨外觀的單一開關。
- DEM 沒有洞穴：新增只覆蓋入口範圍的洞內深度與暗部 pass，位於地表之後、建物之前。入口背向鏡頭不繪製，遠方入口前若另有山體遮擋也不穿透；不清除整個地圖深度、不移動山形或軌道。
- 路基沿線接縫共用邊緣、依兩端地高分別計算坡腳寬度，移除內部端面。結構網格先移到局部原點再轉 Float32，投影矩陣在 CPU 合成，降低跟車時的大座標浮點跳動。
- 前照燈加大柔光與明亮中心。地面光斑沿股道取樣、貼到地面或橋面；共用一份網格，不新增 SpotLight 或陰影貼圖。近景（zoom ≥ 16）才畫，每列只畫行進前端，桌面最多 24 列、窄螢幕最多 8 列，跟隨列車優先。頭尾燈與車窗不受光斑數量限制。
- 保留 `origin/main` 的 `935f3a02` 觀光列車更新，沒有納入其他工作目錄的未提交編制更新。
