# 軌道承托與車頭鎖定 — 2026-09-09

## 使用者回報與範圍

- 高鐵在平坦與起伏模式都只有懸空線條；後續提供台鐵 114 次、11:54、頭前溪附近的截圖。
- 使用者允許若全面橋梁校正難以完成，先讓非交會路段回到地面。本次能共用既有線形補上承托結構，因此沒有全面取消高架或地下層位。
- 手機右側需要明確的車頭鎖定開關。鎖定時仍可縮放、旋轉；解鎖後自由移動，再鎖定回同車。放空跟車使用相同行為。

## 軌道承托

`rail-structures.js` 以現有實體股道的軌面取樣產生一個批次網格：高架段補示意橋面、每 32 公尺沿來源 way 固定里程配置橋墩；地面段以路基填補地形淨空。這些尺寸與間距是畫面示意，不是工程實測或逐橋造型。

- 列車、軌道與橋面共用相同路徑及既有高度函式，不橫移列車，不改派軌、時刻表與交會淨距。
- 平坦模式以零地面承托；起伏模式以目前 MapLibre 地形高度接地。地形資料抵達後重建，未知地面不猜值。
- 地下段不產生橋面、橋墩或路基；原半透明地下列車 pass 保留。
- zoom 14 以下不繪製結構；只建視窗附近路段，更新與原軌道重建共用節流，釋放舊網格。

## 車頭鎖定

- 沿用右側 `followLockBtn`，以鎖定／自由、`aria-pressed` 及可翻譯名稱表示狀態。放空跟車也顯示，群車巡航的原導演行為保留。
- 手機及放空跟車以第一節車廂中心為相機目標，使用既有編組方向和高程。目標置於扣除跟車卡與工具列後的可視地圖中央。
- 使用 MapLibre 的 `transformCameraUpdate` 相機約束；縮放、旋轉、傾斜保留使用者值，只約束中心及高度。
- **相依固定 MapLibre 5.9.0。** 手指尚未放開時不能呼叫 `jumpTo()`，它會 `stop()` 並重設手勢。模組沿用此版本實際的 `_getTransformForUpdate → _applyUpdatedTransform → _update` 管線更新同一 transform；沒有變動 pane 或移動列車座標。升級 MapLibre 必須重跑手勢與分層渲染測試。
- 公開相機約束說明：[MapOptions](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/#transformcameraupdate)。實際採用行為另核對 repo 內固定的 `vendor/maplibre-gl.js`。
- 放空解鎖時暫停自動換車，重新鎖定重新計時；手動調整 zoom 不再被放空近景下限逐幀拉回。
