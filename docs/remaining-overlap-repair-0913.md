# 多站進路修復：2026-09-13

BUILD v0913d。本批調整 75 班台鐵的 82 處進路，另為 4 班加開車保留原先借用的路徑，避免模板來源改派後連帶換股。沒有新增或平移來源股道，沒有增加 hold；非台鐵計畫、groups、handoffs 保持不變。正式站部署不包含在這次工作中。

## 修復內容

先前查核的 101 組局部候選並不全適合一起落成。本批只使用原派車表曾採用的停車節點，保留來源道岔與進出方向；候選先以涵蓋全部 14 天共同營運名冊的局部多車比較篩選，再跑真正的瀏覽器全日閘門。會增加其他配對重疊、依賴未核實月台或無法與前後路段連接的候選不採用。

例：281/1839 北新竹同向追撞、436/447 瑞穗—三民對向互穿、4534/21 山里—臺東錯股，以及汐止、斗六等站待避互穿。75 班可能在不同站有多處調整，因此共有 82 處。

本批新建 156 條路徑記錄，但全部由既有來源節點與既有 ways 組成。完整來源 ways 雜湊未變；既有路徑記錄也未改。新增路徑的 fromGroup／toGroup 依實際來源分組重算。network 的檔案雜湊改變後重新建置層位，沒有偷偷略過來源雜湊檢查。

已知借路車 6841、127、6801、6835 落成自己的原路徑，並以 templateEligible:false 避免這些保護記錄又成為別班模板。其餘未修改車班的實際 pathIds 已逐班比對保持不變。
