# 路線導覽與精選取景

這輪借鏡 GodView 的路線導覽、空白搜尋提示與快速取景。以最新 main 9cb8ce8d 為基準，在 codex/discovery-navigation 獨立 worktree 實作。

## 實作範圍

1. 「軌道與路線」加入導覽：搜尋路線或沿線車站、依系統篩選、正反站序、點站開既有看板、查看全線。顯示設定保留在同一面板的分頁內。
2. 搜尋框空白時顯示可點的站名、當日車次與特色列車範例，不叫用新搜尋 API。
3. 同一面板提供精選取景：台北車站群、文湖線、淡海輕軌、阿里山林鐵。取景座標從已載入路網推得，只經現有 MapLibre 適配層調整鏡頭。
4. 到站看板保留原欄位、字級、等寬對齊與資料來源標示；時刻提高文字對比，倒數使用既有海軍藍淡底。
5. 補上入口說明、繁中／英文／日文文案及公開更新紀錄。

## 與 3D 工作的界線

不改列車位置、軌道線形、地形、建築或模型資產，不修改另一個工作的未追蹤 prototype。導覽模組只讀系統資料；查看全線與精選取景沿用相機 API。站序保持每條原始線的順序，分岔線不併成一條；反向只操作副本。開看板走既有 gotoStn，保留系統身分。

車型展示由現有 3D 工作接續；官方／推估資料標示沿用現有看板，不增加另一套到站推算。

## 列車運行與 3D 的下一批驗收

依使用者複測，軌島目前點擊反應同樣快速，不將初步觀感當成延遲缺陷，也不更動點擊或跟隨狀態機。GodView 車體比圓點更醒目，視覺大小可能影響操作感受；這是待以相同縮放與裝置比較的假設。

在既有 3D 工作上依序驗證：

1. **遠近尺度**：同一路段連續縮放，遠景保持可辨識、近景呈現編組；切換圓點／模型時，中心位置與方向連續，觸控命中範圍跟上可見車體。禁止以避讓改動列車位置。
2. **運行姿態**：直線、曲線、停站、發車各錄一段，兩方向都驗；車廂沿各自軌道位置轉向，不把整列當成一根硬棒轉彎，不因視角改變而改速度。即時校正和表定推演保留現有資料語意。
3. **建築透視**：俯視與傾斜之間連續切換，建築、軌道、車體使用同一地圖相機；驗高樓遮擋、遠近比例及跨層像素對齊，搭配 iPhone 真機檢查。
4. **操作感受**：沿用現有選車、再次點擊取消、疊車選單和跟隨機制，先比車體可見性與命中率；只有量到延遲後才做效能修正。
5. **視覺一致**：奶油紙色、海軍藍、原字體、票牌和既有 sheet 都保留；模型與鏡頭的改進不帶入 GodView 的整套 UI。

以上為下一批實作驗收要求，本輪不宣稱已交付列車模型或改寫 3D 運行。

## 驗收

- Chromium、WebKit 實際操作導覽、搜尋提示與取景。
- 360／375／390／414／640／768px，觸控模式 tap；檢查互動元素相交、裁切、可點擊性與水平溢出。
- 覆蓋全畫面、公告橫幅、更多抽屜、跟車與其他 sheet 互斥。
- 兩個方向站序、淡海分岔線、台北／台中市政府同名站、全台同框裝飾層看板。
- 相機只用既有引擎；驗證投影結果與列車／軌道圖層保持對齊，取景保留模擬時間、倍速與播放狀態；跨系統會明示切到全台同框。
- 多語稽核、公開更新紀錄稽核、查詢面板既有回歸。
