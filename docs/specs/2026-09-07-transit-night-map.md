# 交通模式與暗色霓虹路線

## 本輪已完成

沿用既有亮／暗地圖，暗色自動加入柔和霓虹路線，不增加模式按鈕。面板、字體、票牌與控件保持軌島原有設計。

微光是一層 MapLibre line，與軌道共用 `track-lines` 幾何與可見線別篩選，置於實線、站點與地名之下。不改列車位置、動畫與點擊。亮色、衛星、淡化、隱藏、收集地圖不帶微光；GL 軌道不可用時，維持既有 canvas 退路。

驗證：`verify_night_glow.mjs` 在 Chromium 與 WebKit 均量到開／關微光的實際像素差異，涵蓋五種螢幕寬度、顯示條件、同源篩選與底圖重建；`verify_gl_tracks.mjs` 的原有軌道交叉、站點、跟隨高亮與 canvas 退路回歸通過。BUILD v0907b。

## 公車的接續範圍

GodView 的交通入口提供巴士、小巴、渡輪、電車、纜車分頁，以及路線／目的地搜尋。本輪觀察時路線清單回傳 0 條，尚未驗證其逐路線詳細流程。使用者同意可以納入公車，優先利用軌島已具備的轉乘資料。

第一階段聚焦「選定車站的轉乘公車」：從既有公車轉乘候選選一路線，顯示上下車站、站序、下一班到站，以及有明確身分與有效 GPS 的車輛位置。只在使用者選定路線時取得資料，離開即停止該路線的更新，不開機就輪詢全台車輛。

可沿用的現有程式：

- `bus-transfer-ui.js`：候選班次、轉乘行程、`exactJourneyVehicle` 的車牌與 GPS 時間核對。
- `worker.js`：`/api/bus-transfer`、`/api/bus-leg-live`、`/api/bus-route-stops`。後者需使用本站實際到站結果的 arrival key，不接受任意 RouteUID。
- 地圖：延伸既有 MapLibre 圖層與原有卡片，提供公車標記、選取與到站看板。維持目前網站／App 開放入口的限制。

動工前先核對各系統實際資料覆蓋與道路線形來源：站序資料不等於道路線形，不能以站與站之間的直線當成實際公車路徑。GPS 過期時保留時間標示並停止推演；尚無確定車輛身分時只顯示到站資訊。通過單路線的雙方向、更新中斷與手機驗收後，再擴為可瀏覽多路線的交通圖層。

公車地圖尚未實作；本輪交付為暗色霓虹路線與可直接接續的實作範圍。
