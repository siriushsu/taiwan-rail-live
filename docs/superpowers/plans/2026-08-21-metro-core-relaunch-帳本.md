## 六、網站出貨預設改 shadow（2026-08-22）

`metroCoreFlag()` 最後一層的預設值由 `true` 改成 `false`：**網站出貨走既有 legacy
路徑，Core 只在 `?metrocore=1`（預覽站加同一個參數）時接管。**

為什麼在這一層改，不是回退程式碼：

- 伺服端的逐線 hard gate 還沒綠。預設留在 Core，等於讓還沒驗收的供應鏈直接對到
  使用者；而這批合進來的是 **53 檔混批**，真要回退就是整包回捲，風險與工作量都不
  對稱。預設值放在旗標這一層之後，「Metro 要回退」＝翻一行布林、不必回退程式碼、
  不必重跑一次 15 顆的擇取判斷。
- 反過來，伺服端 hard gate 綠了之後，網站的正式切換點就是**把那一行改回 `true`**，
  單點、可逐字驗、可單獨回捲。
- 三個 rollout 入口的優先序（前面命中就回傳，後面的碰不到）：
  `?metrocore=0/1` → `METRO_CORE_QUERY_MODE` → `window.RAIL_METRO_CORE_ENABLED`
  （App 注入）→ `APP_CFG.metroCore` → 預設值。**App v13 已上架且原生恆開，兩個
  App 注入點都在預設值之前，所以網站的預設值管不到它**——這批完全沒有動 App 分支。
- 驗收：`verify_metro_core_bridge` 新增／改寫兩條靜態契約——「網站預設關閉（shadow）
  且 App 注入點在預設值之前」（把**順序**一起釘住，順序反了 App 會被網站預設值蓋掉）
  與「`?metrocore=1` 仍可顯式開啟」。40 項全通過。

⚠️ **連帶待裁示**：`index.html` 8/21 那條更新紀錄（`metrocorelive`）寫的是「北捷即時
動畫正式換成同一套時間軸」。網站預設翻成 shadow 之後，那句話只對 **App v13** 與
帶 `?metrocore=1` 的人成立，對一般網站訪客不成立。依「更新紀錄只寫做好的功能」，
這條要嘛改寫成只講 App、要嘛暫時撤下、要嘛等網站翻預設時再上——**沒有動它，等裁示**。

## 七、P0-2 收班豁免（2026-08-22）

**缺陷**：P0-2 的基線是「這條線自己近五分鐘的中位數」。末班收車時 Core 的車數本來
就會相對它腰斬 ⇒ 連兩輪之後整批線被判 `reason:'count'` 退回備案，徽章跟著寫
「官方即時（N 線改用備案）」並掛上 `.anom`——**每天深夜一次的假警報**。

**修法**：沿用 P0-5 徽章那條已經在用的**不同來源**對照（`metroCoreLegacyCountForLine`：
官方名冊 → 實際時刻表 → 班距合成）。備案也一起掉到基線一半以下 ⇒ 這個時段本來就在
收班，不判；備案還有車而 Core 沒有 ⇒ 照舊觸發。豁免的那一輪會走 `else` 把當輪車數
推進 history，基線於是**隨營運時段自然衰減**——而且只在獨立來源同意時才衰減，不會讓
真故障把基線自己拉下來（自我漂移）。取不到對照時（使用者不在捷運分頁、那些線沒有
`_tt`）維持原判準，不放寬也不收緊。

**驗收**：`verify_metro_core_defense` 新增 J1–J7（共 50 項全通過）。兩組情境除了
**頁面時鐘**以外每一個輸入都逐格相同（同一份語料、同樣 6 輪建基線、同樣切 `allEmpty`
再跑兩輪），唯一變因是備案在那個時刻有沒有車：

| 判準 | 內容 | 結果 |
|---|---|---|
| J1 | 佈題：收班 legacy=0、營運中 legacy=106（否則 J2/J3 是空判準） | PASS |
| J2 | 佈題：兩組基線都建起來（Core 兩邊都有車可掉，BL 各 21 台） | PASS |
| J3 | 收班：兩邊同時歸零 ⇒ **一條線都不判退回** | PASS `blocked={}` |
| J4 | 收班：徽章寫「班表備案」不是「即時資料異常」 | PASS |
| J5 | **控制組**：同一套輸入換成營運時段 ⇒ 照舊退回 9 條線、`reason='count'` | PASS |
| J6 | **控制組**：營運時段 Core 0 台時徽章明講異常（P0-5 沒被豁免蓋掉） | PASS |
| J7 | **突變對照**：拿掉 `!windingDown` ⇒ J3 轉紅（證明 J3 不是「反正那時段不判定」） | PASS |

**同輪修掉的驗收器自身缺陷**：這支腳本原本整支吃**真實牆鐘**，於是 B2（「既有路徑
真的有車可畫」這個正向對照）與 D4（徽章要顯示異常態）**只有在營運時段跑才會綠**，
深夜跑就假紅——而深夜正是要驗末班收車的時候。改成把頁面的 `Date` 整個平移到指定
時刻（時間照常流動，不是凍結），伺服端語料用同一個位移產生；全部既有情境釘在 08:30，
(j) 自己搬到 02:30 再搬回來。
