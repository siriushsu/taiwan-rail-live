# 列車自然柔光 A 版（v0912n）

2026-09-12 使用者確認 natural-3 預覽 A 版：夜間亮度 100%、日間 70%，只保留開關。

## 實作

- 每節車廂兩團漸層柔光，沿實際編組位置逐節散開；差異固定，不用時間亂數，也不畫整列膠囊外框。
- 夜景使用暖色 `#ffc66d`，日景使用原始車次／路線顏色。晨昏連續過渡；日夜光影關閉時依地圖明暗外觀配色。
- 「更多 → 列車光環」預設開啟，以 `trainmap-train-halo` 保存開關。頭尾燈、車窗與既有跟隨標記維持各自行為。
- 3D 使用共用 GPU 批次，地面與地下最多各一批。柔光深度沿車廂水平面計算，避免被地面截成半圈；保留建物遮擋及既有地下透視規則，不寫入深度。
- 五種遠景車牌／圓點畫法共用快取貼圖；已有 3D 車體的列車沿用原本跳過遠景標記的規則。
- 沒有新增實際光源或陰影貼圖。關閉時不產生光暈頂點；不移動列車、車牌、股道或命中位置。
