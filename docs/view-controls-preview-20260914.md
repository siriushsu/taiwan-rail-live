# 觀看工具預覽

從正式版 v0914b（9b576f9f）建立獨立工作區，使用者已核可預覽並授權部署，正式 BUILD v0914c。

網站以右側六個分類展開設定；觸控版以「觀看」按鈕展開橫向分類列。分類為視角、地圖、列車、標示、導覽、畫面。搬移原本的 DOM 控制項，沿用既有狀態與動作，沒有複製兩套開關。更多保留語言、個人功能、診斷、資料與資訊。

App 預覽沿用 mobile-shell 版面，尚未產生原生安裝包。App 的 prepare-web 已包含 rail-3d 整個目錄，新模組沿用既有資產複製路徑。

驗收腳本：
- `scripts/verify_view_controls.mjs`：Chromium / WebKit；360、375、414、520、768、844×390 橫放、1280、1440。每分類的控件命中與觸控尺寸、俯視、列車比例設定、關閉與更多不重複。可用 `WIDTHS=844,1280,1440` 重跑受影響尺寸。
- `scripts/verify_view_controls_layers.mjs`：五個寬度 × 預設、觀看、告警、更多、列車面板、全畫面；量測全部既有控件與新工具的矩形相交及 elementFromPoint。
- `scripts/verify_view_controls_immersive.mjs`：App／網站 × Chromium／WebKit，進入沉浸後重開觀看、退出沉浸，以及重新載入後退出，共 8 項。
- `node scripts/check_i18n.mjs`：英文／日文覆蓋。

驗收發現並修正：舊外觀分段鈕小於 44px、橫放跟車側欄遮住新入口、更多面板遮住觀看入口、桌面工具欄與縮放鈕相撞。使用者實測另抓到沉浸模式讓觀看面板無法重開，已移除沉浸狀態的面板封鎖並補上進出與重載驗收。沒有更改相機或列車位置運算。

本機可用 `python3 -m http.server 5248 --bind 127.0.0.1`，地圖網址 `/?train=117&t=12:00&scene=3d&z=18`。雙尺寸展示頁在本機忽略目錄 `output/view-controls/preview.html`。

正式出貨已補上公開更新紀錄與翻譯，導覽、林鐵地形與車頭朝上驗收改走觀看入口；沉浸模式的雙引擎進出與重載已加入 ship-web gate。原生 App 安裝包仍未發布。

使用者錄影補修：DEM 未就緒時 MapLibre 回 0，改讀同一個實際 DEM 圖磚的就緒狀態，並在 MapLibre 本幀準備後同步橋墩與車體。保留有效零海拔。實體股道恢復遠景的橫向辨識加寬；車長、車距、座標與近景比例不變。舊邏輯受控延遲 DEM 對照產生 217.76m 假橋墩，新版最大 8.96m；兩方向列車比例與地表跨層比對均通過。verify_ground_size.mjs 已加入雙引擎出貨 gate。
