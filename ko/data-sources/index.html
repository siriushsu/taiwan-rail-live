Rail Island 데이터는 어디서 오나요?

대만철도 OpenData · 교통부 TDX · MRT 운영사 공개 정보 · OpenStreetMap을 통합해요. 출처별로 시간표 · 실시간 보정 · 역 · 선로 형태를 담당해요.

실시간 지도 열기역 정보 찾기

주요 출처와 용도

대만철도 OpenData
일별 시간표 · 역 기본 정보 · 차종 코드 등 안정적인 데이터예요.
교통부 TDX
대만철도 실시간 지연 · 역 정보, 고속철도 · MRT · 경전철의 노선 · 역 순서 · 시간표 · 배차간격 정보를 정부 데이터 개방 라이선스 제1판에 따라 사용해요.
운영사 데이터
이용 허가와 기술 여건이 허용하는 범위에서 운영사의 도착 카운트다운 · 열차 운행 정보 · 운행 공지로 화면을 보정해요.
OpenStreetMap
일부 선로 형태를 보완해요. OpenStreetMap 기여자의 데이터를 ODbL에 따라 사용해요.
대만철도위키
구간열차 차종 추정은 커뮤니티가 정리한 편성 운용표(CC BY-SA 4.0)를 개작했어요. 공식 시간표는 세대를 구분하지 않아서 참고용이에요.
지도 타일
웹 거리 지도는 OpenFreeMap, 위성 영상은 Esri World Imagery를 사용해요. 앱에서 OpenFreeMap을 불러오지 못하면 Stadia Maps로 전환해요. 실제 저작권 표시는 지도에 나와요.

왜 API 하나만 사용하지 않나요

시간표 · 역 · 선로 형태 · 열차별 상태 · 운행 공지는 여러 출처에 흩어져 있고 시스템별 공개 항목도 달라요. Rail Island는 출처별 차이를 그대로 유지해요. 실시간 신호가 있으면 보정하고 시간표만 있으면 추정임을 분명히 밝히며, 한 가지 데이터 정밀도를 모든 시스템에 적용하는 것처럼 꾸미지 않아요.
