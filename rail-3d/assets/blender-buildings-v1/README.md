# Blender 建築外觀 v1

2026-09-07，由使用者提供的 22 款原生 Blender 模型匯入。原生檔留在原型；這裡只放地圖需要的原樣網格與 metadata，catalog.json 鎖定逐檔 SHA-256。

Z-up、單位公尺。ENU-baked 模型不可再重複套分件平移／旋轉。local-facade 的原始方向未核實；地圖定位另存 placement.json，不改原始 metadata。全部工程尺寸、高程仍未知，展示外觀不是測繪成果。

外觀自製，無照片貼圖。地理輪廓 © OpenStreetMap contributors，ODbL-1.0，來源見模型 metadata 與 placement.json。
