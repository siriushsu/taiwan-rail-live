# 花蓮車站 外觀 v1

跨站廊道・迎客大傘・月台棚。自製簡化外觀與半透明檢視，並非測繪模型。

建模分件：花蓮跨站大廳、花蓮售票大廳、迎客大傘、花蓮前站、花蓮後站、月台棚、月台棚、月台棚。

輪廓保留 OSM 原始經緯度及天井，不把相鄰系統移到同一位置；所有高度與底高均為展示參數，真實建物與軌道高程為 `null`。實際列車、地下月台與沒有來源的連接設施仍待整合。

來源、參考用途及精度見 [metadata.json](metadata.json)。輪廓 © OpenStreetMap contributors，ODbL 1.0；自製程序幾何見 `station-models.js`，沒有使用照片貼圖。
